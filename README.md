# Linea Italia

Gioco nel browser: progetta la metropolitana delle città italiane sulle mappe reali di OpenStreetMap.

- Traccia linee e stazioni, crea interscambi, aggiungi corse espresse e limitate.
- Gestisci cantieri, budget e prestiti; imposta le tariffe a zone.
- Gli abitanti scelgono tra auto, scooter, bus, bici, piedi e metro in base ai tempi di viaggio.

I numeri sono stime del gioco, non dati reali. Mappe e dati © OpenStreetMap contributors.

## Avvio in locale

```
node server.js
```

Poi apri http://localhost:5180. Il gioco vero e proprio è nella cartella `public/` (HTML, CSS e JavaScript statici).
